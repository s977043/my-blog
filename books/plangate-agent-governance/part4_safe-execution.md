# 第4部 承認後を安全に自律化する

前の部で、実装前に「何を任せてよいか」を決めました。

ここからの問いは変わります。

> **承認された境界の内側を、どうすれば人間が張り付かずに任せられるか。**

そのために必要なのが、

1. **Enforcement** — 越えてはいけない境界を実行時に検査する
2. **Verification** — 現在の成果物が条件を満たしたかEvidenceで確認する
3. **Authority** — AIが自律的に進める範囲と、最終決定権を分ける

です。

Gateの目的はAIを止め続けることではありません。

**止まるべき場所を明確にすることで、その間を自律化しやすくする。**

この部では、承認後のExecutionをその観点から見ます。
