# 第7部 自分のプロジェクトへ導入する

ここまでの章では、Plan / Gate / Hook / Evidence / Context / Evalまで扱ってきました。

しかし、最初から全部を入れる必要はありません。

現行PlanGateの段階導入ガイドも、

> **使うものだけを段階的に増やす**

ことを前提にしています。

この部では、

1. **どこから始めるか**
2. **何が起きたら次の仕組みを足すか**
3. **PlanGateを入れない方がよいのはいつか**
4. **最小の1タスクで判断境界を一周するにはどうするか**

を扱います。

導入のゴールは、最大構成へ到達することではありません。

> **いま困っている失敗に対して、必要な境界だけが機能している状態を作る。**

ことです。

導入後は、仕組みを足すだけでなく見直します。

~~~text
Keep
Strengthen
Simplify
Remove
~~~

の4つで、Boundaryの強さと維持コストを定期的に見直します。
