# レビューの仕組み自体を改善し続ける

River Review導入はゴールではありません。

運用では次を観測します。

- False Positive / False Negative
- Review Coverage
- Suppressionの増え方
- Human Escalation
- Skill Evaluation
- Review Cost
- 同じFindingの再発

改善対象はモデルだけではなく、Skill・Context・Judgment Placement・Human Boundaryです。

レビュー判断を組織資産として持つなら、その資産にも保守と回帰テストが必要になります。
