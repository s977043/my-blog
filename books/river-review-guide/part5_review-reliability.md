# 第5部 AIレビューそのものを信頼しすぎない

## この部で答える問い

> **AIレビューの出力ではなく、レビューという実行そのものをどう検証するのか。**

自然な文章でFindingが返ると、「実行できた」「十分見た」「根拠が正しい」をひとまとめにしやすくなります。

この部では4つに分けます。

1. **レビューは完遂したか** — Review Coverage
2. **Findingの機械的条件は満たされているか** — Verification
3. **必要なContextだけを読めているか** — Context Engineering
4. **複数観点をどう分けて統合するか** — Review Team

> **Findingが0件だから安全、とは限らない。**

## 読み終えたとき

Finding数だけではなく、**Coverage / Verification / Context / Reviewer Roleを別々の品質軸として確認**できる状態を目指します。

第6部では、レビューで得た判断を次回へ残し、改善する方法へ進みます。
