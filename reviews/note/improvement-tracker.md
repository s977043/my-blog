# note 過去記事の改善台帳

個人の note 記事を 1 本ずつ改善するための台帳です。累計 PV の多い順に進めます。

- PV とスキ: 2026-11-07 に note のダッシュボードで取得（累計）
- 全 40 本: PR 作成済み 2、作業中 1、要確認 7、対象外 3、未着手 27
- 手順と比較結果: [reviews/note/published/n23ec87da4cdb.design-skill-pilot.md](published/n23ec87da4cdb.design-skill-pilot.md)

## 状態の意味

| 状態 | 意味 |
| --- | --- |
| 未着手 | 改善案を作っていない |
| 作業中 | 改善案の作成から PR までの途中 |
| PR 作成済み | 著者のマージ待ち |
| マージ済み | リポジトリに反映済みで、note は未反映 |
| 対応済み | note に反映し、スマホで表示を確認した |
| 要確認 | 着手してよいか著者の確認が必要 |
| 対象外 | この台帳では改善しない |

## 1 本の進め方

1. `accessibility-audit` と `design-critique` で改善案を作る。図があれば `design-elevation` も使う
2. 別のモデルが案を検証し、両者が採用可とした案だけを反映する
3. 意味や主張に関わる案は著者判断に回す
4. ⚠️ 付きの PR を作る。マージと note の「更新する」は著者が行う
5. スマホで表示を確認したら、この台帳を「対応済み」にする
