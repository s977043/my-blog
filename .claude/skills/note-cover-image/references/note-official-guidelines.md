# note公式: 見出し画像ガイド

最終確認日: 2026-09-05

本ファイルは `note-cover-image` スキルが参照する、note公式情報の要点メモ。
仕様は変わる可能性があるため、Webアクセス可能な場合は実行時に公式ページを再確認する。

## 1. 記事の見出し画像

公式ヘルプ「登録画像の推奨サイズ一覧」では、記事の見出し画像の推奨サイズは **1280 × 670 px**。
画像容量は **最大10MB**。
推奨サイズと異なる画像はトリミングされて表示される場合があり、ブラウザとアプリで見え方が異なる。

### 容量上限は note 公式内で記述が競合している（2026-09-06 時点・未解決）

- 公式ヘルプ「登録画像の推奨サイズ一覧」は、本ファイル最終確認時点で **「各画像の容量は最大10MB」** と記載する
- 一方、note 公式 info「画像の容量・解像度を上げました！」（2024-06-28）は **「アップロードできる画像サイズが10MBから20MBに増加」** と告知している
- 同じ告知に含まれる「拡大時の長辺4,000px対応」はヘルプ側にも反映されているため、ヘルプが単純に未更新のままとは断定できない
- どちらが**記事の見出し画像**の現行仕様かは一次情報で確定できていない。したがって `check_note_cover.py` の `MAX_BYTES` は保守的に厳しい側の **10MB のまま**とする（どちらかを誤りと断定しない）

## 2. 見出し画像の作り方

公式ヘルプ「タイトルと見出し画像のコツ」「見出し画像のポイント」で案内されている主な考え方:

- 記事内容に合った画像を使う
- 見出し画像は記事の入口であり、本でいう装丁に近い
- タイムラインや一覧で目に留まりやすいよう、細部よりも大きなシルエット・構図・色面を意識する
- SNSシェアを意識する場合、2:1前後の横長比率が扱いやすい
- シリーズ記事では表紙に統一感を持たせる

本リポジトリでは、ファイル作成時の正本を **1280 × 670 px** とし、「2:1」は構図上の近似目安として扱う。

一次情報:
- https://www.help-note.com/hc/ja/articles/360012426353
- https://www.help-note.com/hc/ja/articles/900000061623

## 3. Canvaについて

note公式ヘルプでは、note内のCanva連携は **2025-12-01で終了**したと案内されている。
Canvaを使う場合はCanva側で画像を作成・保存し、noteへアップロードする。

## 4. クリエイターページ / マガジンのヘッダー画像との違い

記事の見出し画像と、クリエイターページ / マガジンのヘッダー画像は用途が違う。

公式ヘルプでは、クリエイターページ / マガジンのヘッダー画像について:

- 推奨比率: **1.91:1**
- 基本サイズ: **1280 × 670 px**
- よりきれいに表示する場合: **1920 × 1006 px**
- 表示場所や端末によって中央部分がトリミングされる

と説明されている。

本スキルは、ユーザーが単に「noteの表紙」「ヒーロー画像」と言った場合、**記事の見出し画像**をデフォルト対象とする。

## 5. Repository-specific heuristics

以下はnote公式仕様ではなく、本リポジトリでの制作上のヒューリスティック。

- 重要な文字・ロゴ・概念を端へ寄せすぎない
- 主見出しは縮小表示でも読める大きさにする
- 記事タイトル全文を画像に複製しない
- 小さな説明文・箇条書きを表紙に載せない
- 技術記事は、概念を1つか2つに絞って視覚化する
- 日本語テキストは可能なら決定的な文字レイヤーで合成する
- 生成AIが文字を描いた場合は、すべての文字を目視で確認する
- 画像の意味が本文の因果・方向・境界を変えていないか確認する

公式仕様と本ヒューリスティックが競合した場合は、公式仕様を優先する。
