# GPT-6 モデル移行計画

更新日: 2026-09-26

## 目的

本リポジトリで行う記事の企画・執筆・レビュー・公開準備に適した GPT-6 モデルを選び、既存の品質・速度・コストの役割を保ちながら段階的に評価する。モデル名の一括置換や、モデル選択だけを根拠にした複雑なルーティング追加は行わない。

## 現状

- このリポジトリに OpenAI API の呼び出し、モデル設定、モデル選択 UI、またはモデルルーターは見つかっていない。
- 作業の主な対象は Markdown の記事、編集・レビュー用の指示、記事の公開準備である。
- `AGENTS.md` と `CLAUDE.md` はモデル名に依存しない共通規約・Claude Code 向け案内を担う。`.claude/skills/article-humanizer-ja/SKILL.md` には「GPT-5.6 Terra を言い換えない」という固有の用語ルールがある。
- 記事、レビュー、計測ログにある過去のモデル名や比較結果は履歴であり、移行対象ではない。

## 推奨モデルと役割

**評価前に標準モデルを決めない。** GPT-6 Sol を日常的な企画・編集・レビューの候補として含め、現行モデルと比較する。Sol は OpenAI の現行ガイダンスで、強い推論を要するコーディングや日常作業向けに位置付けられているが、このリポジトリでの標準候補として妥当かは作業結果で判断する。

| モデル | このリポジトリでの候補用途 | 判断 |
| --- | --- | --- |
| GPT-6 Sol | 記事の企画・レビュー・編集 | 現行モデルとの比較候補にする |
| GPT-6 Astra | 複雑な事実境界の確認、多段階の難しい判断 | Sol との差が測れた作業に限り比較する |
| GPT-6 Luna | 大量の定型分類・抽出など | 需要が確認できた場合に限り比較する |

Codex のセッションでモデルを選ぶだけであれば、リポジトリのランタイム実装変更は不要である。GPT-6 モデルの利用可否やアカウント条件は、この計画だけでは確認できていないため、実施時に Codex のモデル選択画面で確認する。

## 段階的な評価

### 1. 基準作業を選ぶ

代表的な作業を3〜5件選び、入力資料、使う指示、期待する成果物、合否条件を固定する。候補は記事レビュー、レビュー指摘の反映、記事企画、公開前確認とする。公開済み記事の編集や外部公開は評価に含めず、既存の人間承認ゲートを維持する。

### 2. Sol を現行条件と比較する

同じ資料と指示で、現在使えるモデルと GPT-6 Sol の結果を比較する。評価項目は、事実誤り・重要な見落とし、成果物の完全性、指示遵守、不要な変更、人の修正量、完了時間、再試行、エスカレーションとする。利用画面で取得できる範囲に限り、トークン量と費用も記録する。レビューや事実確認では、同一モデル内の反復と別モデルによる独立レビューを分けて評価し、モデルを替えたこと自体を独立性の保証とみなさない。

### 3. 必要な作業だけ Astra と比較する

Sol の評価で難度や品質の課題が確認された作業に絞って Astra を比較する。Astra の品質上の利点が、速度・費用への影響に見合う場合にその作業の候補とする。すべての作業を Astra に集約しない。

### 4. 指示の変更は失敗に結び付ける

GPT-6 Astra は指示ファイルの文面に強く反応するため、既存の `AGENTS.md`、`CLAUDE.md` と、評価対象の指示を確認する。確認質問が過剰になる、合意済みの自走範囲で止まる、または過剰な検証を行うなど、再現可能な失敗があった場合だけ該当箇所を小さく直し、同じ作業で再評価する。共通規約とClaude固有の案内を混同しない。

### 5. 運用判断を記録する

作業種別ごとに、採用モデル、評価根拠、既知の制約、確認日を記録する。モデルの利用可否や製品仕様は変わるため、採用時に OpenAI 公式ドキュメントと Codex の実環境で再確認する。モデル選択だけで API、SDK、設定、プロンプト、スキーマを変更しない。品質、速度、コストの測定結果が揃うまでは GPT-6 ファミリーの標準割当を宣言しない。

## 完了条件

- 代表作業で現行モデルと Sol の比較結果が記録されている。
- Astra または Luna を使う場合、対象作業と比較結果に基づく理由が記録されている。
- 指示を変更した場合、観測した失敗と再評価結果が対応付いている。
- 記事の公開や公開済み記事の変更に対する人間承認ゲートが保たれている。
- 採用判断と未確認事項が、実際の利用可否・計測可能性を越えて断定されていない。
