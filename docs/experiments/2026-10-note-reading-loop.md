# 実験: note で「読む → 反応する」ループを回すと、自分の記事は見つけてもらえるか

- ID: `EXP-NOTE-READ-202610`
- 期間: 2026-10-06（月）〜 2026-11-02（日）の 4 週間
- 担当: 読む・反応するのは著者本人（アカウント操作は代行しない）。候補選び・計測・記録はエージェント
- きっかけ: 「読まないと、読まれない。」（https://note.com/csfive/n/n4957269ffc33 、2026-10-04）。読む → 反応する → 相手に通知が届く → 相手が見に来る、という導線の主張

## 仮説

note の弱点は露出（2026-09 の実測で PV / インプレッション 45%）。同じテーマの記事を読み、丁寧に反応すると、反応した相手と、その読者から自分のプロフィールと記事が見つかりやすくなり、インプレッション・フォロワー・スキが増える。

- 根拠の強さ: 中。引用元の記事は筆者の体感と、別の分析（58,000 件）の引用が中心
- この実験で測れるのは「4 週間でこの程度動くか」まで。対照群が無いので、因果は言い切らない

## やること（週ごと）

1. 候補（エージェントが毎週 5〜7 本を用意）から、本当に読みたい 3 本を選んで最後まで読む
2. 良かった記事にスキを付ける。**今回はコメント・引用・マガジン追加はしない**（2026-10-05 著者決定）
3. 下の「行動ログ」に 1 行ずつ記録する（記録はエージェントが代わりに書いてよい）

数をこなす「スキ回り」はしない。読んだ記事にだけスキを付ける。

**この実験が測るもの**: 引用元の記事が勧める 4 段階（スキ → 丁寧なコメント → マガジン追加 → リンク付き引用）のうち、最も軽い「読んでスキ」だけで動くかどうか。引用元の記事はコメントや引用のほうが効くとしているので、効果が出なくても「交流全体に効果が無い」とは言えない。その場合は、次の 4 週間でコメントを足した版を試すかどうかを判断する。
