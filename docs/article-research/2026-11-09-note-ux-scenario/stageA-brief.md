# UX シナリオ検証 A（テキスト判定、read-only）

ファイルを編集・commit しない。指定の出力ファイル 1 つにだけ書く。

読むもの（これ以外の scratchpad/ux/ のファイル、特に version-map.txt は読まない）:
- シナリオ: <scratchpad>/ux/scenarios.md
- 記事の 2 版（どちらが改善前か改善後かは知らされていない）: <scratchpad>/ux/text/ の 6 ファイル（各記事 X と Y）

## 手順
1. scenarios.md のタスクのうち「テキストだけで判定できる A」を、各記事に割り当てられた読者像のシナリオで実行する
2. 各タスクを X と Y それぞれで別々に判定する（成功／部分／失敗）。根拠は版の行や見出しを引用する
3. 記事ごとに、どちらの版がシナリオ上よいか、または差がないかを書く
4. 片方の版にしかない誤り（意味の変化、欠落）があれば指摘する

AI ペルソナによる判定で、実読者の検証ではない。版の作り方を推測できた場合はその旨を書く。

## 出力形式
記事ごとに: タスク × 版の表（判定、根拠）、総合（X / Y / 差なし）、気づいた誤り。
